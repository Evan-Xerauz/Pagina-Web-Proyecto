MEJORA BOGOTÁ — ARCHIVOS PARA ACTUALIZAR TU PROYECTO

1. Copia el contenido de esta carpeta dentro de tu proyecto Mejora-Bogota-.
   Combina las carpetas existentes y reemplaza los archivos con el mismo nombre.
   No borres la carpeta images que ya tienes.
2. Conserva images/ciudad.svg: aparece en tu captura, pero no fue adjuntado.
   Se mantiene su referencia en la portada. Este paquete no incluye ese archivo.
3. En js deben quedar los tres archivos juntos: app.js, utilidades.js y
   funcionalidades.js. Ya incluyen sus import y export.
4. Abre index.html con Live Server. Los módulos necesitan servir el proyecto
   por HTTP; no abras el HTML directamente mediante doble clic.

CAMBIOS REALIZADOS
- Fotografías en seis categorías de Inicio y Explorar.
- Migas de pan Inicio > página actual en las siete páginas interiores,
  con comentarios en HTML y CSS. Inicio no necesita una ruta de regreso.
- JavaScript convertido a funciones flecha y dividido en tres módulos.
- "use strict" explícito en cada módulo; se conservan const y let.
- Carga del módulo app.js justo antes de cerrar body en los ocho HTML.
- CSS original intacto; las reglas de imágenes y migas de pan se añaden al final.
- Se conservan la lógica, los textos y los comentarios existentes, salvo las
  dos explicaciones de carga con defer, ajustadas para describir los módulos.

ARCHIVOS DE JAVASCRIPT
js/app.js: importa e inicia las funciones de cada página.
js/utilidades.js: datos y funciones compartidas (secciones originales 1 a 4).
js/funcionalidades.js: crear reporte, fotografía, filtros, seguimiento y contacto
  (secciones originales 5 a 9).

PRUEBAS REALIZADAS
Se revisaron las ocho páginas en Chromium, a 1280 y 390 píxeles de ancho.
Se comprobaron carga de módulos e imágenes, migas de pan con teclado,
validación de formularios y fotografía, guardado y persistencia de reportes,
búsqueda y filtrado, consulta por código, contacto sin envío y recuperación
ante datos locales dañados sin sobrescribirlos. No hubo errores de JavaScript.
También se compararon los HTML con los originales y se verificó que el CSS
previo se conserva byte a byte. ciudad.svg quedó fuera de la comprobación
visual porque no fue adjuntado. No se hizo una certificación completa W3C.
