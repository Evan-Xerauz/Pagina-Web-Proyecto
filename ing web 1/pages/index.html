Proceso sencillo

¿Cómo funciona Mejora Bogotá?

Cuatro pasos para documentar una incidencia y facilitar su seguimiento.

  1. 01

    Identifica

    Encuentra un problema en una vía o espacio público de tu localidad.

  2. 02

    Reporta

    Selecciona la categoría, describe el caso, ubícalo y adjunta evidencia.

  3. 03

    Consulta

    Guarda el código interno para revisar las novedades y el estado del reporte.

  4. 04

    Verifica

    Confirma si el problema continúa o aporta evidencia cuando haya sido solucionado.
