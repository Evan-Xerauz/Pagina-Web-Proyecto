Antes de crear un reporte

  • Revisa los reportes existentes para comprobar si alguien ya registró el mismo problema.
  • Describe un problema por reporte. Si hay varios daños diferentes, registra cada caso por separado.
  • Indica la dirección o una referencia que permita encontrar el lugar, también si está en una zona rural.

Consultar seguimiento

¿Qué pasará cuando habilitemos los reportes?

  1. Recibirás un código interno cuando el reporte se guarde correctamente.
  2. El equipo revisará la información y si ya existe un caso similar.
  3. Si se presenta una solicitud ante una entidad, el seguimiento indicará a quién se dirigió y el radicado obtenido.
  4. Podrás consultar las respuestas y las novedades registradas.

Registrar un reporte no garantiza una intervención ni un plazo de solución. Para conocer más sobre el proyecto, consulta las preguntas frecuentes.
